## About the visible tests

You can run `grader.check(...)` yourself at any point. Those visible checks
verify **properties** — shapes, conservation laws, scaling relations,
consistency between your own functions. They do **not** verify that your answer
is numerically right; hidden tests do that on submission.

A green visible check means *not obviously broken*, not *correct*. This is
deliberate: a test that asserted the answer would hand you the answer.
